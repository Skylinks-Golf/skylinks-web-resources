# skylinks-web-resources (archived)

**Archived Oct 22, 2026.** The Skylinks website now lives in one repo, [Skylinks-Golf/skylinks-website](https://github.com/Skylinks-Golf/skylinks-website). Its CSS library (`assets/css/wordpress_css_lib.css`) is the one stylesheet for the site; `css/skylinks_style_library.css` here is an older copy and isn't used.

**Keep this repo public and don't delete it.** Lightspeed sales receipts load the SGC QR code from:

    https://raw.githubusercontent.com/Skylinks-Golf/skylinks-web-resources/main/images/sgc_qr_code.png

Archiving keeps that link working. If the QR code ever moves, update the receipt templates first (`projects/Lightspeed/Retail/receipt_templates/` in SLE).
